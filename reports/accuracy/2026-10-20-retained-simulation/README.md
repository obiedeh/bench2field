# Retained simulation person accuracy

Existing local Safety simulation artifacts contain 60 paired source sidecars and images: 45 positive person tight semantic boxes and 15 negatives. The labels are recorded Isaac Replicator boxes, not boxes inferred from presence labels. Matching frozen Thor inference records retain the actual full YOLOX-s heads. The adapter verifies every sidecar/rendering, inference image, raw array, model and original postprocessing source hash before reproducing every saved detection exactly. Frame identity and dimensions bind the PNG labels to JPEG inference copies; the encodings are not pixel-identical. No new model inference or dataset download occurred.

The saved strict confidence threshold remains 0.3, NMS threshold 0.45, person class 0, top-left 114 letterbox, NCHW BGR float32 0..255, and already-decoded [1,8400,85] output. No duplicate output decoding, class-label substitution or geometry correction was introduced. All 60 frames' maximum raw objectness × person-class scores are below the original confidence gate, so suppression and metric matching cannot recover absent proposals. A model/scene or upstream execution issue remains possible; this result does not identify its cause.

`accuracy.json` records 0 true positives, 0 false positives, 45 false negatives, recall 0, undefined precision and person AP@0.5 of 0 for the frozen thresholded output. This is one class and one IoU, not COCO 80-class mAP or evidence for the existing speed benchmark budgets. The source is correlated generated simulation with unsigned human review. No perception or speed promotion is accepted.

The generator repository carries MIT terms; background asset redistribution rights are not separately established. This use is local. Images, complete labels, raw tensors and frame-by-frame source records remain outside Git. The committed provenance contains hashes and aggregate counts only. This resolves availability of compatible local labels for a bounded development measurement; independently reviewed field/held-out labels remain absent.

Validation: 170 tests pass with host GPU visibility; scoped Ruff and Python 3.10-targeted mypy pass. The earlier sandbox run passed 166 with 3 skips and failed the existing TensorRT hardware check because CUDA was hidden; both failure and passing host logs are retained. Nine handwritten unit cases validate label conversion/rejection and do not establish real detector quality. Source was clean at the evaluation commit recorded in `accuracy.json`.
